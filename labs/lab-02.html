Lab 02

The question

2016 U.S. Presidential Election

How do different mapping techniques change the way the 2016 U.S. presidential election results are represented and interpreted?

The data

2016 U.S. Presidential Election

I used the election_2016 layer provided for the lab in ArcGIS Online. The dataset contains 3,139 county records and includes Democratic and Republican vote shares, total votes, and other election-related attributes. One data problem is that Alaska appears as 28 polygons with the same statewide election values repeated in every row. After accounting for these duplicates, the national vote totals still do not match the certified results, showing that the dataset has additional data limitations.

Cartogram Data

For the cartogram, I used the LAB02_state-votes-2016.csv file supplied with the lab. It was created by aggregating the election_2016 data to the state level. The repeated Alaska values were corrected in this file, but the remaining differences between the dataset totals and the certified national results were intentionally left unchanged. The cartogram uses Votes_total to size the states and Pct_DEM to represent the Democratic vote share.

The method

2016 U.S. Presidential Election

I used four different mapping techniques to represent the same election data. First, I created a predominant category map using DEM_per and GOP_per. Second, I used proportional symbols based on Total_Votes to show differences in voting volume between counties. Third, I calculated standardized Democratic vote-share scores using z-scores and displayed them with a diverging color scale centered at z = 0, which represents the average county in the dataset. Finally, I created a state-level cartogram in go-cart.io, using Votes_total to determine state size and Pct_DEM to represent Democratic vote share.

What I found

2016 U.S. Presidential Election

I found that the same election data can look very different depending on the mapping method. The classification test showed that quantile made high Democratic vote shares appear more widespread, while equal interval concentrated the highest values in far fewer counties. The proportional symbol map showed voting volume more clearly because counties with more total votes had larger symbols. The z-score map showed how each county's Democratic vote share differed from the average county. Finally, the cartogram emphasized states with more total votes by making them larger. Together, these maps showed that mapping choices strongly affect which patterns are visually emphasized.

What this does not show

2016 U.S. Presidential Election

These maps do not provide a complete or perfectly accurate picture of the election. The dataset has important limitations. Alaska appears in 28 rows with the same statewide results repeated, which would greatly inflate its totals if the rows were simply summed. Even after accounting for this issue, the national totals in the dataset do not match the certified election totals.

The maps are also affected by visualization choices. Different classification methods can make the same vote-share data appear either more widespread or more concentrated. A raw-count map can emphasize places with more voters, while a rate map shows the share of votes instead. Proportional symbols reduce the influence of geographic area but can overlap in densely populated areas. The z-score map shows how counties differ from the average county, not from a 50–50 vote split. Finally, the cartogram changes the geographic size and shape of states in order to emphasize voting volume, so it should not be interpreted as an accurate representation of physical geography.
